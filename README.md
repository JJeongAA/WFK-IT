## 🇺🇦 Інструкція для студента (Ukrainian)

### ▶️ Як запустити гру (2 способи)

**Спосіб 1 — VS Code + Live Server (рекомендовано):**
1. Відкрий папку проєкту у **VS Code**.
2. Встанови розширення **«Live Server»** (Extensions → шукай "Live Server").
3. Клікни правою кнопкою на `index.html` → **«Open with Live Server»**.
4. Гра відкриється у браузері. Після зміни коду просто **онови сторінку (F5)**.

**Спосіб 2 — через Python (якщо є Python):**
```bash
# у папці проєкту виконай:
python -m http.server 8000
# потім відкрий у браузері:  http://localhost:8000
```

> ⚠️ Не відкривай `index.html` подвійним кліком (file://) — деякі зображення можуть не завантажитись. Використовуй сервер (спосіб 1 або 2).

### 🎯 Твої завдання

Файли з підказками мають позначку `🎯 ЗАВДАННЯ`. Знайди їх і напиши код.

| # | Файл | Функція / місце | Що зробити |
|---|------|-----------------|------------|
| 1 | `js/game.js` | `renderDishes()` | Показати картки страв (приклад — `renderDifficulty()` поруч) |
| 2 | `js/game.js` | `completeStage()` | Нарахувати бали та перейти до наступного етапу |
| 3 | `js/game.js` | `endGame()` | Показати екран результату (бали, %, зірки, культура) |
| 4 | `js/dishes.js` | `stages` у 4 стравах | Додати етапи готування (bibimbap — приклад) |

### ✅ Як перевірити, що все працює
1. **Головний екран**: видно 3 рівні складності і **5 карток страв** (завдання 1).
2. Клікни страву → гра починається, етапи проходяться, **рахунок росте** (завдання 2).
3. Після останнього етапу → **екран результату** з балами, майстерністю, зірками (завдання 3).
4. Усі 5 страв мають повноцінні етапи готування (завдання 4).
