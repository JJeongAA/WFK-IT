# 재료 사진 넣는 방법 (How to add ingredient photos)

이 폴더에 아래 **파일명 그대로** 사진을 넣으면 게임에 자동으로 적용됩니다.
사진이 없는 재료는 자동으로 이모지로 표시되므로, **원하는 것만 부분적으로 넣어도 됩니다.**

## 파일 규격 (Specs)
- **파일명**: `<재료id>.png` (아래 표의 id 사용, 소문자)
- **형식**: 배경이 **투명한 PNG** 권장 (그릇에 얹었을 때 자연스러움)
- **크기**: 정사각형 권장, 256×256 ~ 512×512px
- 예: 당근 사진 → `carrot.png`

## ⚠️ 저작권 주의
직접 촬영한 사진이나 **저작권이 자유로운(CC0/퍼블릭도메인)** 사진만 사용하세요.
인터넷의 아무 사진이나 넣으면 저작권 문제가 생길 수 있습니다.

## (선택) 그릇 배경 사진
- `../bowl.png` 를 넣으면 담기 단계의 그릇 배경으로 쓰입니다. (없으면 기본 그릇 그림 사용)
